== 后续导入必须保留的来源语义

* 查看/view→view，新增→create，编辑→update，审批→approve，导出→export；未知动作报错，不猜测。
* 无/空白不产生授权，“无”不是优先deny；空白还应给预览警告。
* 全部仅展开经校验的动作白名单，不写通配符或开放未实现接口。
* 本人语义用SELF；查看/编辑本人按已定稿规则将相关动作都限制本人，并在预览说明。
* 人员、建号、角色模板和用户角色是独立动作；附件不提供账号密码、有效期或岗位自动授权依据。
