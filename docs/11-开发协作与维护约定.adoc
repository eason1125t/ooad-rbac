= 开发协作与维护约定
:toc:

== 每次接手的阅读顺序

先读根目录AGENTS.md和link:01-项目总览与开发规划.adoc[01唯一进度]，再看相关03规则、06契约、07数据库、09测试。历史资料用于追溯决策，不用旧阶段的“未实现”覆盖当前状态。

当前采用面向功能的结构化设计、单一Spring Boot构建。Java类/Spring组件是实现技术，不因此改成另一套设计方法。普通可逆技术选择可自行处理，真正外部阻断集中记录并继续不受影响工作。

== 变更顺序

. 明确需求、已实现/未来边界和受影响规则，更新01/03及13追踪。
. API先改contracts/openapi.yaml；生成TS及14接口清单，补充成功与拒绝测试设计。
. 数据库只增加新的Flyway迁移，不改V1–V3等已应用文件；重生成08/ER，验证空库与存量升级。
. 按功能服务、HTTP适配、页面纵向实现；同步版本、范围、CSRF和审计。
. 执行与改动匹配的验证，记录真实结果；远程协作同步、提交/推送、部署分别依据授权处理。

== 代码与依赖

构造器注入，服务名表达职责，不给每个类机械配接口。authorization核心不能依赖security/HTTP/OA/PMIS；业务不能读授权内部Mapper，identity不反向依赖authorization。跨模块事务由administration组合公开服务。

源码顶部说明文件用途及联系，关键算法简短说明原理。Java使用Spotless AOSP，TypeScript strict及Prettier；统一UTF-8。新增依赖说明用途，精确锁版本并验证；不使用latest或动态范围。

不将操作者从客户端userId获取、不按账号/角色名称判断平台资格、不关闭CSRF、不为未声明端点默认放行。日志不记录密码、Cookie、SessionID、token、真实人员或原始Excel，不开启SQL入参DEBUG。

== 文档目录与生成

当前正文采用00–14中文编号；README.md和AGENTS.md保留工具惯例，作为短入口。原始任务提示词和Excel输入不改名，不把来源文件当当前说明。

[cols="3,5",options="header"]
|===
|维护对象 |唯一入口与检查
|当前状态 |01，只保留最新结论；旧阶段归历史资料
|业务规则/未来规划 |03与10；已有用户v2决定不可被实现便捷性悄悄改写
|API说明 |06为讲解；14由OpenAPI生成，不手改生成清单或schema.generated.ts
|数据库说明 |07为设计；08和ER由Flyway生成，不写第二份建库SQL
|测试证据 |09记准确计数、日志及跳过，reports保存本地执行产物
|需求追踪 |13为CSV，保留FR/NFR编号，未来项不能标完成
|历史文件 |历史资料中文索引；正文只修复相对引用并标历史快照，保留决定/证据
|===

----

校验会检查中文文档链接/图片/include、编号与历史迁移引用。渲染输出reports/docs/00-文档导航.html及其他HTML，生成物不进Git；图片和可编辑Mermaid源保留docs/diagrams。

== 测试与交付

优先真实MySQL/Redis容器及安全/授权反例，不用H2替代。必要检查通过后，除非代码变化、失败或用户明确复测，不机械重复大范围测试。纯文档整理执行生成、链接、渲染、浏览器文档检查即可，不宣称重新跑业务测试。

核心生产包行覆盖≥80%、分支≥70%，由check-ci-tests.py检查全部包及必需容器执行，不能排除权限代码刷分。确认接口no-store、403/409/503可恢复，且不自动重放写请求。

交付说明结果、范围、测试、限制和下一步建议。只标记实际执行为PASS；计划、未实现、外部缺项和可选跳过分别说明。本地通过不代表远程CI、教师验收、性能或生产就绪。

== 文件、数据和Git

保留当前未提交修改。禁止批量删除文件/目录；需要删除时一次只处理一个明确路径，批量清理由用户手工完成。移动说明文件时先验证源/目标均在本项目，逐文件明确移动，不覆盖原始用户资料。

原始Excel、个人资料、.env、Cookie/令牌、数据库备份不提交。演示只用合成账号，1234不用于数据库、MCP或正式账号。已授权查看/测试不自动授权上传、部署或合并；提交/推送仅在用户明确授权时进行。

分支默认codex/前缀；不要因整理说明覆盖工作区、重置数据库或恢复旧授权。提交前复核差异、生成物与秘密，现有main的早期CI不得冒充当前切片结果。
