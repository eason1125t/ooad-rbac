角色与授权

基本信息 / 权限配置 / 角色成员

选择一个应用内角色，配置允许的资源动作，并在角色成员中分配人员和有效期。与用户详情共享同一授权流程。

示例：OA文档阅览者 → OA公文 / 查看。菜单层级不隐式授予子项权限。

应用与资源

基本信息 / 资源权限 / 管理员与范围

资源树与权限动作就近维护。示例管理员oa-admin的管理应用为OA，示例人员范围为工程分公司及下级；平台可以显式选择全公司。

拥有业务操作权限不自动拥有委派权，业务管理员不能通过修改角色扩大自身范围。

操作审计

按应用、操作者、目标和时间查询；展示授权来源、前后差异及有效期。只读且遵守管理范围。
