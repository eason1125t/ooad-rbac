== 后端覆盖与浏览器覆盖的区别

后端另覆盖迁移/复合FK、组织非法层级与移动、版本/重放/过期、双上限/多来源/时间边界、范围/自授/管理员成员、自然过期与责任待接管、多个专用角色分步交接、最后平台管理员、正式口令/强改密、限流、审计回滚和依赖故障。

它们不是每项都由浏览器17组逐步点击。手工T01–T13包含补充操作路线，不能把手工条目数、Java用例数、浏览器组数直接相加称为总测试数。

== 可重复命令

从根目录执行，需要Java、Node/pnpm、Python及可用Docker Linux引擎：

[source,powershell]
----
backend/mvnw.cmd -f backend/pom.xml verify
python scripts/check-ci-tests.py
pnpm -C frontend run verify
pnpm -C frontend run test:admin
python scripts/schema_docs.py
pnpm -C frontend run docs:api
python scripts/check_docs.py
pnpm -C frontend run docs
pnpm -C frontend exec node scripts/ui-smoke.mjs
----

test:admin依赖前面产生的backend/target打包JAR及三个前端dist；报告不包含登录口令、Cookie或预览token。Windows使用已安装Edge，其他环境需实际设置CHROME_PATH。

当前开发库已运行且显式demo时，可补充只读/会话检查：

[source,powershell]
----
./scripts/verify-local-login.ps1 -BaseUrl http://127.0.0.1:15173
./scripts/verify-demo-accounts.ps1
./scripts/verify-identity-api.ps1
./scripts/verify-authorization-api.ps1
----

第一条端口按实际入口修改。另有scripts/mysql-smoke.ps1 -MySqlBin指定本机已安装MySQL二进制，可启动独立13308实例验证迁移；它不是必须手工清开发库的脚本，具体参数应查看脚本头部。
