== 目录与代码约定

backend为单一Maven入口，按identity/authorization/security/administration/audit/imports/oa/pmis/bootstrap分包，shared仅响应/错误契约。身份切片的IdentityDirectory公开读写规则、PasswordHasher算法端口由security适配；administration组合权限、身份锁与审计事务。
构造器注入；服务名表达职责，不给每个类配接口。授权内部持久化仅由authorization本模块读取；业务通过PermissionChecker和公开范围接口访问，不能访问其Mapper。AccessManager负责角色/委派规则；administration的EmployeeAssignment组合身份和授权公开接口完成调岗事务。
Java Spotless AOSP风格、UTF-8；TypeScript strict与Prettier；代码顶部说明功能及文件联系，关键算法保留简短原理注释。
当前共享shell仅覆盖三个应用确实相同的登录/导航/状态/原型；后续完整业务页面回到各自apps，不能让共享包成为万能业务目录。

== API与数据库变更

先更新requirements/traceability与contracts/openapi.yaml→契约校验/生成模型→测试设计→实现。公开、登录、权限三个入口声明互斥且运行时默认拒绝。
成功data、错误code/message/traceId、时间ISO8601 Z、ID十进制字符串；未来分页排序规则见design与契约。
DDL只用新增Flyway迁移，已应用迁移不得重写；schema_docs.py生成字典和ER。每次变更核对FK/唯一键/索引/数据迁移，授权覆盖写有expectedVersion和审计。
日志只用traceId等必要上下文；不记录密码、Cookie/SessionID/Token、SQL入参中的个人资料；不打开MyBatis SQL参数DEBUG。

== 运行与统一验证

Compose仅启动隔离端口MySQL/Redis，宿主后端自行设置环境变量；数据库密码与引导密码没有默认值。
前端scripts/run-frontends.ps1启动三个进程，优先5173–5175，端口不可用时回退15173–15175并输出实际入口；本机当前为http://127.0.0.1:15173/admin/。跨平台dev:all仍使用默认端口。OA_DEV_URL/PMIS_DEV_URL配置admin到另两端的代理；不要混用localhost和127.0.0.1。
CI使用Testcontainers；应提供Docker并禁止以跳过集成测试代替绿灯。用户已授权将当前规划/骨架首次归档至指定私有仓库；远程Actions结果单独读取，不将本地通过冒充CI通过。以后每次远程写入仍遵循用户授权，不自动部署或合并。
入口：根目录 backend/mvnw.cmd -f backend/pom.xml verify；pnpm -C frontend run verify；pnpm -C frontend run docs。README提供可复制命令。pnpm12构建许可使用allowBuilds；esbuild明确允许，Puppeteer安装脚本关闭，浏览器使用现有Edge或CHROME_PATH。
测试按影响执行，完成必要检查后不机械重复。只称实际运行的检查为PASS，未实现/环境不足分别标NOT_IN_SCOPE/BLOCKED/SKIPPED。
