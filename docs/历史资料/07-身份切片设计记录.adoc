== 当前切片边界

按已确认v2完成组织、人员、账号的后端基础及最小审计。先定义唯一OpenAPI的27操作（原8+新19），再实现新增V2迁移。此文不构成另一份契约或DDL；当前实现覆盖以下场景，具体运行结果统一在verification记录。
所有admin身份管理操作同时要求具体权限点和admin:platform:manage，统一走Spring方法授权及PermissionChecker。这些身份基础接口保持仅平台管理；业务管理员的应用委派/人员责任在authorization-slice另行实现，不能借演示平台入口访问全公司身份资料。
岗位/组织变动的原子换角留给下一授权切片；人员PUT只编辑姓名/电话。组织移动先预览再确认，15分钟有效并绑定操作者、目标/整树版本；含已授权人员的子树移动返回409 DEPENDENT_AUTHORIZATION_NOT_READY，不能跳过尚不存在的角色范围影响分析。

== 数据与事务

V1不可改写。V2增加规范组织名/唯一根/同父重名约束、组织闭包/目录版本锁、负责人、人员/账号版本与强制改密标志、移动预览及审计。业务角色表/权限算法不加入授予者状态依赖。
组织结构及人员归属写锁目录版本，避免建员工与停用/移动组织并发越界；账号停用/离职在独立平台管理员保护锁下核验最后管理员。必要目标按稳定ID顺序锁定。写入、版本变化、本人角色撤回及审计同一事务，失败全部回滚。
本人离职停用自己的账号并增加auth_version、撤回自己的用户角色，不修改角色定义或其他员工关系；恢复在职不自动启用账号/恢复角色。当前被引用的组织负责人需先显式解除绑定，避免留下无效负责人。
正式临时口令随机生成，仅响应一次，强制改密；demo新测试账号与现有目录一致为1234。新密码至少12字符且不超过72个UTF-8字节。强制改密账号仅可csrf/me/password/logout，不提供管理或业务访问；改密后旧身份全部失效。Redis按账号失败次数和IP尝试数限流，失败设施503，超限429，不泄露账号是否存在。
审计只记录ID、状态、变更字段及版本，不记录姓名/电话/口令/散列/会话标识。账号响应不包含password_hash。暂不提供审计导出。

== 编码前验收场景

[cols="1,4,5",options="header"]
|===
|用例 |操作 |预期
|IF-01 |V1空库、已有V1数据分别升级V2 |迁移/回填/闭包正确，V1校验和不变；唯一根/同父重名/外键真实拒绝
|IF-02 |匿名、缺权限、只有演示入口、缺CSRF、未知API |401/403默认拒绝；不执行任何管理写入
|IF-03 |创建非法层级、环、超8层、重复编码/同父名称 |422或409，目录及审计无半完成记录
|IF-04 |合法空子树移动、过期/他人/重放/变更后预览 |合法移动更新闭包及版本；其他分别410/409，不信任客户端目标
|IF-05 |有已授权人员的子树移动 |409明确说明依赖，绝不隐式撤销或忽略其授权
|IF-06 |创建人员/查询分页/只编辑普通资料 |人员不自动建号或授权；分页/排序/过滤安全；伪造岗位或组织字段400
|IF-07 |显式建号、一对一冲突、弱/旧密码、强制改密 |建号不授角色，临时值仅响应一次，散列不泄露；强制账号业务403，改密旧会话401
|IF-08 |员工离职/账号停用、最后平台管理员 |本人身份撤销，其他员工的角色及可用权限不变；最后管理员拒绝停用
|IF-09 |管理员本人角色撤销/失权 |其他人的既有业务权限继续有效，不能级联撤权
|IF-10 |expectedVersion冲突或审计写入失败 |409或事务回滚，资料/身份版本/成员不部分提交
|IF-11 |登录失败5次/IP尝试超限，Redis故障 |429/503，未知和已存在错误账号同401语义，不永久锁号
|IF-12 |独立MySQL/Redis、字段字典/ER、OpenAPI/生成TS/Apifox |真实集成实跑，生成物同源，远程协作视图回读一致
|===

上述设计已由16项新增真实MySQL/Redis容器用例、10项策略测试及原有26项回归验证；测试项和设计场景不是一一计数。正式环境临时密码策略为单元验证，强制改密路径在真实HTTP/Redis链验证；不声称生产部署验收。运行结果、历史失败修复及已知限制统一见verification和plan。
